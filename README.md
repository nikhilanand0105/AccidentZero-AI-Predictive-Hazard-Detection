# AccidentZero AI - Predictive Hazard Detection

This repository contains the source code, reports, presentations, and visual outputs for the AccidentZero AI project.

## Repository Structure

- `Project/`: Source code and project files.
- `Project_Poster/`: Project poster.
- `Project_Report/`: Detailed project report.
- `Project_ppt/`: Presentation slides.
- `Visual Output/`: Visualizations and output results.
